# TASK-109: Define ThinkIO-Native Webview Presentation Architecture

Define the shared UI architecture for ThinkIO's native VS Code webviews before replacing raw JSON output with product-grade views.

## Required Work

- Define the shared shell, navigation, toolbar, governance, status, empty, loading, and error states.
- Define how each view receives and renders projections.
- Decide which code belongs in shared webview helpers versus per-view scripts.
- Keep all presentation local to ThinkIO and independent from external VS Code plugins.
