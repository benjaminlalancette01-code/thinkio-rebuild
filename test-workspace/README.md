# ThinkIO Extension Host Test Workspace

This fixture is opened by `.vscode/launch.json` when running `ThinkIO: Extension Host`.

It contains the minimum files needed for VS Code activation and projection loading:

- `thinkio.config.json`
- `views/kanban.json`
- `views/mindmap.json`
- `views/thinkio-runtime-flow.json`
- `views/dashboard.json`

Canonical project development still happens in the repository root. This workspace is only for local Extension Development Host smoke testing.
